## The full forward pass

Reading `TransformerClassifier.forward` top to bottom, you now know every step:

```python
mask = make_padding_mask(token_ids, self.pad_idx)      # lesson 6
x = self.token_embedding(token_ids) * sqrt(d_model)     # lesson 6
x = self.pos_encoding(x)                                # lesson 3
hidden = self.encoder(x, mask=mask)                     # lessons 2, 4, 5
pooled = self._masked_mean_pool(hidden, token_ids)      # lesson 6
logits = self.classifier(self.classifier_dropout(pooled))
```

Six lines. Roughly 2.9 million parameters. ~89% accuracy on 4-way news classification.

## Where to go next

You have built an **encoder-only** Transformer — the BERT family's shape, suited to
classification and representation tasks. The parts you have not built yet:

- **Causal (masked) self-attention** — mask out future positions so a token can only attend
  backwards. This single change turns an encoder into a generator.
- **Cross-attention** — queries from one sequence, keys and values from another. The bridge in
  encoder-decoder models like the original translation Transformer.
- **Autoregressive decoding** — generate one token at a time, feeding each output back as input.
  This is what makes GPT-style models work.
- **Pre-training and fine-tuning** — train on a large unlabeled corpus with a self-supervised
  objective, then adapt to a specific task with far less labeled data.

Every one of these is a modification of machinery you now understand rather than something new.
