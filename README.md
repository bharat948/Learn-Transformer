# Learn Transformer

An interactive, hands-on course on the Transformer architecture. Ten lessons run from an
RNN/LSTM recap through attention, positional encoding, multi-head attention, the encoder block,
the classification head, and training — ending in a capstone where you assemble a full encoder
block yourself.

Two things make it different from a written explainer:

- **The visualizations run on real weights.** Attention maps, the learned positional table,
  training curves, ablation results, and confusion matrices are all exported from an actual
  trained PyTorch checkpoint, not hand-authored to look plausible.
- **You write the code.** Nine browser exercises — softmax, scaled dot-product attention, head
  splitting, Add & Norm, the feed-forward block, masked pooling, cross-entropy, and the full
  encoder block — run against real assertions and have to pass.

## Running it

```bash
npm install
npm run dev              # http://localhost:5173
```

Other scripts:

```bash
npm run build            # production build
npm run preview          # serve the production build
npm run verify:exercises # check every exercise solution passes and no starter passes trivially
```

## How it is built

- **Vite + React 18 + TypeScript**, routed with React Router.
- **Lessons are MDX** in `src/lessons/NN-slug/index.mdx`, registered in `src/data/lessons.ts`
  along with their kind, learning objective, and milestones. Adding a lesson is a new `.mdx`
  file plus one registry entry.
- **Exercises** live in `src/data/exercises.ts` (starter code, reference solution, assertion
  tests) and execute in a **Web Worker** with a 2-second timeout, so an accidental infinite loop
  cannot freeze the page. Your code is saved on every keystroke.
- **Model artifacts** are JSON in `src/data/artifacts/`, generated by
  `scripts/export_web_artifacts.py` in the parent PyTorch project. Retrain the model, re-run the
  exporter, and every figure updates.
- **Design**: Source Serif 4 for prose, Inter for headings and chrome, JetBrains Mono for code;
  a warm near-monochrome palette with a single accent, so the only saturated colour on screen is
  the data. Data-viz tokens are centralized in `src/lib/viz.ts`.

## Layout

```
src/
  lessons/          MDX lesson content
  data/
    lessons.ts      lesson registry (kind, objective, milestones)
    exercises.ts    coding exercises + tests
    artifacts/      JSON exported from the trained model
  components/
    layout/         app shell, sidebar, lesson layout
    ui/             code sandbox, milestone card, quiz checkpoint
    viz/            interactive figures
  lib/
    progress.tsx    localStorage progress + saved code
    runCode.ts      Web Worker test runner
    viz.ts          data-visualization colour tokens
```
